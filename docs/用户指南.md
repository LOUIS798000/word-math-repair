# Word 公式修复工具 · 用户指南

本文面向直接使用安装包的用户，介绍安装、界面操作、规则含义与常见问题。开发与打包说明见 [README](../README.md)。

---

## 1. 安装

### 安装版（推荐）

1. 双击 `WordMathRepair-Setup-<版本>.exe`；
2. 按向导选择安装目录（默认安装在当前用户目录，无需管理员权限）；
3. 安装完成后，桌面与开始菜单会出现「Word 公式修复工具」。

工具自带公式修复引擎，**不需要额外安装 Python、Node.js 或 Microsoft Word**。只有在使用「原生打印」或「保存时同时导出 PDF」时才需要本机安装 Microsoft Word。

### 便携版

`WordMathRepair-Portable-<版本>.exe` 无需安装，复制到任意目录双击即可运行。配置与渲染缓存写在 `%APPDATA%\word-formula-repair-tool`，删除程序不会自动清除该目录。

### 系统要求

- Windows 10 / Windows 11（64 位）
- 约 500 MB 磁盘空间（安装后）
- 处理大文档建议 4 GB 以上内存

---

## 2. 第一次使用

1. 启动后会自动载入内置示例文档，可直接体验修复效果；
2. 点击右上角 **打开文档**，或把 `.docx` 文件拖入窗口；
3. 左侧勾选需要启用的规则（默认「推荐」预设已适合大多数文档）；
4. 在顶部切换 **页面排版 / 优化对比** 查看修改前后的差异；
5. 确认无误后点击 **保存文档**，另存为新文件。

> 工具只处理 `.docx`。旧版 `.doc` 请先用 Word 另存为 `.docx`。

## 3. 界面说明

| 区域 | 作用 |
| --- | --- |
| 左侧规则栏 | 按「公式结构 / 正斜体与符号 / 段落排版 / 公式编号 / 字体」分组，可逐条开关 |
| 场景预设 | 一键套用「推荐 / 全部 / 无 / 试卷 / 论文」规则组合 |
| 页面排版 | 以 A4 纸张样式预览正文与公式，高亮显示被修改的公式 |
| 原生打印 | 调用本机 Word 生成高保真页面预览，适合最终检查 |
| 优化对比 | 按规则筛选，逐条查看「修改前 → 修改后」的公式卡片 |
| 修复后 / 原始 | 切换预览中显示修复后的结果或文档原始内容 |
| 搜索框 | 按题目、公式关键字或段落序号定位 |

「在 Word 中打开」会用系统默认程序打开当前文档，便于在真实排版环境中复核。

## 4. 规则说明

### 公式结构

- **消除积分虚线框**：积分号后缺少被积项时，Word 会显示 `[::]` 虚线占位框。规则会补全遗漏的被积项并清除空占位。
- **修复括号上标**：修复 `(式子)^n` 被拆散成独立括号与上标的结构，使用括号配对回溯，避免误删嵌套括号。
- **极限下标居中**：`lim`、`max`、`limsup` 等的下标改为正下方。
- **求和/乘积上下标居中**：`∑ ∏ ⋃ ⋂` 的上下标改为正上方、正下方。
- **二重积分区域居中**：`∬_D`、`∭_Ω` 的区域标识固定到积分号正下方。
- **固定积分号高度**：限制积分号随被积函数过度拉伸。
- **修复代入线高度**：`f(x)|_{a}^{b}` 的竖线随内容自适应高度。
- **集合大括号修复**：`{ ... }` 定界符随内容高度伸缩。
- **分段函数左对齐**：分段函数的条件列统一左对齐。

### 正斜体与符号

- **正斜体规范**：数字、微分 `d`、自然常数 `e`、转置 `T` 用正体；变量保持斜体；中文整词保持正体。
- **工程符号规范**：特征数 `Re`、`Ma` 用斜体；下标 `max`、`ref`、单位 `Pa`、`m/s`、希腊常数 `π`、`Δ` 用正体（依据 GB 3101 / ISO 80000）。
- **拆分连写函数**：把 `lncosx`、`sin2x` 等拆成 `ln`、`cos`、`x` 并恢复间距。
- **全角符号转半角**：公式中的全角括号、等号、数字改为半角。
- **连字符改为减号**：短横线 `-` 统一为数学减号 `−`。

### 段落排版

- **公式行距不被截断**：把「固定值」行距改为「最小值」，防止高公式被裁掉。
- **取消公式段落对齐网格**：避免文档网格把公式行撑成双倍行高。
- **独立公式居中**：左对齐或右对齐的独立公式改为居中。
- **清除公式上浮/下沉**：去掉字符位置偏移，使公式与正文基线对齐。

### 公式编号

- **编号右对齐（不丢失）**：把公式后的 `(1)` 或公式内的 `#(1)` 改为「公式居中 + 编号右对齐」，编号为可更新的 SEQ 域。
- **自动为独立公式编号**：按出现顺序为所有独立公式编号 `(1)(2)…`，默认关闭，论文模式会开启。

### 字体

- **公式字体设为 Times New Roman**：把公式及正文中的西文字符、数字统一为 Times New Roman。该规则会改动全文字体，建议先预览再保存。

## 5. 场景预设

| 预设 | 适用场景 |
| --- | --- |
| 推荐 | 默认组合，适合大多数 OCR 转换文档 |
| 全部 | 开启所有规则（含自动编号） |
| 无 | 全部关闭，仅查看文档 |
| 试卷模式 | 不自动编号，其余规则开启 |
| 论文模式 | 全部开启，并自动编号 |

---

## 6. 保存与导出

- **保存文档**：始终另存为新文件，不会覆盖原文档；
- **同时导出 PDF**：勾选后会在保存时调用本机 Word 导出同目录 PDF；未安装 Word 时会提示导出失败，但 `.docx` 仍会正常保存；
- 公式预览中的高亮仅用于定位，不会写入文档。

---

## 6.1 批量修复

点击顶部 **批量修复**：

1. 在文件选择窗口中按住 `Ctrl` 或 `Shift` 选择多个 `.docx`；
2. 选择保存结果的文件夹；
3. 工具按当前已勾选的规则逐个修复，完成后弹窗汇总成功与失败数量。

输出文件命名为 `原文件名_修复.docx`；若同名文件已存在，会自动追加 `_2`、`_3`，不会覆盖已有结果。批量模式使用与单文件保存相同的规则与 PDF 导出选项。

---

## 7. 从右键菜单启动

安装版会在 `.docx` 文件的右键菜单中添加 **用 Word 公式修复工具打开**。右键任意 `.docx` 选择该项即可直接载入，**不会更改系统默认的 Word 打开方式**。

工具已运行时再次从右键菜单打开文件，会在当前窗口载入该文档。便携版不注册右键菜单，请先启动工具再拖入文件。

## 8. 常见问题

**打开文档后公式没有变化？**
确认左侧对应规则已勾选，并切换到「修复后」查看；有些规则只有在检测到特定结构时才生效，状态栏会显示各规则的命中数量。

**提示「无法启动引擎」或窗口空白？**
确认安装目录未被安全软件隔离，且 `resources\engine\engine.exe` 存在。可尝试以普通用户身份重新安装。

**「原生打印」一直加载？**
该视图依赖本机 Microsoft Word。未安装 Word、Word 正在弹窗或文档受保护时会失败，改用「页面排版」即可，不影响修复与保存。

**保存后公式仍然显示虚线框？**
先确认原文档中的虚线框是 Word 的公式占位符，而不是普通文本 `[::]`。如仍无法消除，欢迎提交样例文档反馈。

**杀毒软件误报？**
安装包未做代码签名，部分安全软件可能拦截未签名程序。可将安装目录加入信任列表，或使用源码方式运行。

**卸载后配置还在？**
为保留个人设置，卸载不会删除 `%APPDATA%\word-formula-repair-tool`。如需彻底清理，手动删除该目录即可。
